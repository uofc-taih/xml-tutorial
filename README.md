## Setup

Install Quarto and compile with `quarto preview` for a quick view on how things look.

## Glossary?

The best glossary option for Quarto I found is this:
```sh
quarto add extension debruine/quarto-glossary
```

However, it doesn't allow plural (\gls vs. \glspl in latex), doesn't spell out the full term the first time it's used, and the glossary table page looks old-fashioned. Maybe we should just spell things out manually instead.
